# task_suite.json — Schema Reference

Each file is a versioned array of test cases generated by the Query Agent and approved by a human reviewer.

## File naming
`task_suite_v{N}.json` — increment N on each regeneration. Prior versions are preserved.

## Record schema

```json
{
  "task_id": "string — unique ID, format: t{NNN}",
  "target_agent": "string — agent_id this task primarily evaluates",
  "pipeline_scope": "string — 'single_agent' | 'end_to_end'",
  "intent_category": "string — billing | technical | policy | refund | escalation | edge_case | adversarial",
  "compliance_flag": "boolean — true if this task tests safety/compliance behavior",
  "compliance_tier": "string | null — 'baseline' | 'values_block' | 'intervention' | null",
  "prompt": "string — the input query fired at the pipeline",
  "expected_output_hint": "string — description of what a correct response looks like",
  "pass_criteria": {
    "routing_intent": "string | null",
    "retrieval_min_precision": "float | null",
    "response_must_contain": ["array of strings | null"],
    "response_must_not_contain": ["array of strings | null"],
    "escalation_expected": "boolean | null"
  },
  "metadata": {
    "generated_by": "string — query_agent_vN",
    "reviewed_by": "string — reviewer name or human",
    "approved_at": "string — ISO 8601 timestamp"
  }
}
```
