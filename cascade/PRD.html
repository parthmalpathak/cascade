Executive Summary
What we're building and how we'll know it worked.
Problem
Teams building multi-agent LLM pipelines have no systematic way to identify which model performs best at each stage — or where their pipeline is breaking down. End-to-end testing masks per-stage failure modes and produces no actionable signal about where to improve.
Solution
Cascade is a local-first, agent-agnostic benchmarking framework. It reads your pipeline's agent manifests, auto-generates a tailored test suite, runs systematic model-combination experiments with per-stage scoring, and produces a leaderboard with SHIP / CONDITIONAL / HOLD verdicts. A 3-stage customer support pipeline ships as the reference implementation.

The Core Problem
Why errors compound and why end-to-end scores lie.
The Cascade Effect
A model with 89% accuracy at each of 3 stages produces ~72% end-to-end. Errors compound. This is why end-to-end benchmarks are misleading — they hide where a model breaks down and make it impossible to optimize individual stages.
ModelRoutingRetrievalResponsePipeline ★ComplianceVerdict
Claude 3.5 Sonnet94%88%91%82%89%SHIP
GPT-4o96%79%88%74%81%CONDITIONAL
Gemini 1.5 Pro89%85%83%72%76%CONDITIONAL
Llama 3 70B81%74%79%58%61%HOLD
Pipeline score = product of stage scores (not average). This surfaces the compounding effect intentionally.

Users
Two primary personas with different entry points.
Primary User
The Deployer
Role: AI PM or ML engineer who owns a live multi-agent pipeline
Technical level: Comfortable with Python and LLM APIs; not a researcher
Goal: "Is my current model combination optimal? Where is my pipeline breaking?"
Writes manifests Reviews test suite Reads leaderboard
Secondary User
The Learner
Role: Developer or PM new to multi-agent AI
Technical level: Knows prompting; unfamiliar with eval frameworks
Goal: Understand how model choice and hyperparameter tuning affect real pipeline outputs
Uses reference pipeline Runs auto-mode
User Stories
Five epics covering the full user journey.
Epic 1 — Plug In Your Workflow
As a Deployer, I want to register my agent workflow via agent_manifest.json files so that Cascade understands my pipeline without requiring code changes.
✓ Schema documented with required fields: agent_id, role_description, input_schema, output_schema, system_prompt, constraints
✓ CLI validates manifest on load — schema errors before any run starts
✓ Reference pipeline ships with 3 pre-written manifests as examples
✓ workflow.yaml declares execution order and state passed between agents
Epic 2 — Test Suite Generation (Query Agent)
As a Deployer, I want the Query Agent to auto-generate a test suite tuned to my workflow so that I don't write test prompts by hand.
✓ Generates ≥30 test cases per agent (configurable)
✓ Tests span 4 categories: happy path, edge case, adversarial/safety, ambiguous input
✓ Outputs versioned task_suite_vN.json — prior versions preserved
✓ Generation completes in ≤3 minutes for a 3-agent workflow
✓ Human review gate: no run starts without explicit approval
Epic 3 — Benchmark Run Loop
As a Deployer, I want to run benchmarks against model combinations and iteratively improve, with scores accumulating into a leaderboard.
✓ Per-run scorecard: Pass@1, Pass@3, compliance tier pass rates, pipeline composite, verdict
✓ After each run: "Change model for any agent? [y/n]" — interactive swap loop
✓ Auto-run: cost estimate preview → user confirmation → max-flow scheduler → checkpoint/resume
✓ Lite mode (--lite): 10 tasks/agent, 1 worker — spot-check in minutes
Epic 4 — Grader Agent & Scoring
As a Deployer, I want outputs scored automatically per-agent so I can trust the leaderboard.
✓ Scores every agent output on Task Accuracy (Pass@1/3) + Safety Compliance (3 tiers)
✓ Pipeline composite = product of stage scores (surfaces compounding effect)
✓ Results written to results/{run_id}/grader_output.json
✗ Rubric design (LLM-as-judge vs ground-truth matching) — V2
Epic 5 — Dashboard
As a Deployer, I want a local Streamlit dashboard that shows all my runs and lets me compare model combinations.
✓ Leaderboard table: model combo, per-agent scores, pipeline composite, compliance, verdict
✓ Cascade Effect view: bar chart showing per-stage score vs pipeline composite
✓ Filter by workflow, date range, verdict
✓ Auto-refresh on new run (5s polling)
✓ Export: self-contained HTML snapshot for sharing

Technical Risks
Specific risks with mitigations — not generic warnings.
RiskLikelihoodImpactMitigation
Query Agent generates generic tests that miss agent intent MediumHigh Human review gate is mandatory; track approval rate; iterate Query Agent prompt if <80% pass
Grader Agent inconsistency across runs (same output, different score) MediumHigh Temperature fixed at 0; pin model version; add grader regression tests
Permutation explosion causes runaway API costs MediumMedium Cost estimate preview + mandatory confirmation before auto-run; Lite mode for spot-checking
AWS Bedrock rate limits throttle auto-run workers MediumMedium Configurable worker count; exponential backoff in runner; checkpoint/resume = no lost work
agent_manifest.json schema too rigid — users can't describe their agents LowHigh Ship schema with 3 real examples; allow extra_fields passthrough; gather feedback in V1.1
